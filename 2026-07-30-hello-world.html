代码高亮

Python 代码块自动高亮：

def fibonacci(n: int) -> int:
    """返回第 n 个斐波那契数"""
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b

# 测试
print(fibonacci(10))  # → 55
